# C1 資料準備 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. 此目錄不是 Git repository，直接在已授權的 workspace 實作，不建立 branch／commit。

**Goal:** 建立可驗證的資料讀取介面、20 正＋20 負 debug 樣本，以及人工審核材料。

**Architecture:** `common/data.py` 讀取及驗證 JSONL；準備腳本連結 gRefCOCO queries 與 COCO instance boxes，下載選定圖片，產生本地審核頁。人工審核獨立保存，不把官方 no_target 標籤視為已經人工確認。

**Tech Stack:** conda、Python 3.12、Pillow、unittest；不安裝模型依賴。

**Spec:** `proposal.md` §3、§6 C1；使用者已選擇 COCO＋gRefCOCO 並授權開始。

## Global Constraints
- 共 20 正例、20 負例；排除多目標，保留 train 來源 IDs。
- pixel xyxy；candidate IDs 與 boxes 同序，依 COCO annotation ID 排序。
- 圖片路徑相對 JSONL 所在目錄；不可只放正解框。
- 不改 A6 的 RefCOCOg UMD 設定，不宣稱跨資料集 image-disjoint 已驗證。
- 下載保存來源 URL、revision、SHA256；人工審核未完成時 C1 保持進行中。

## Review Focus
- 空候選與 proposal_miss：groundable=true 不改成負例。
- 布林值、NaN、越界、退化框、重複 IDs：讀取時報 sample／line 錯誤。
- 索引指向錯誤物件：GT debug 正例需與對應 candidate 框一致。
- 原始 xywh 轉 xyxy，不修改 query 文字。
- 正負 query 共用同圖同候選；原始 -1 不成為 Python index。
